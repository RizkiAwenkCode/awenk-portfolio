# 04 Selected Work

## Purpose

Give recruiters and engineering managers a quick, factual view of selected work without exposing confidential material.

## Approved content

Flagship: Aplikasi Konsolidator Data Ditjen Adwil. Description: Konsolidasi dan integrasi data antarsistem.

Supporting work: LEGASI - spatial data visualization; RedKar - location-based incident reporting; W-Track - EDC maintenance ticketing.

## Layout

Use one wide flagship card followed by three supporting cards. Each project includes a clearly labeled NDA-safe visual placeholder until approved assets are supplied.

## Interactions

Flagship card links to the separate Case Study page. Supporting cards may link only when an approved destination exists; otherwise they remain informational.

## Accessibility

Use descriptive project headings, text alternatives for visual placeholders, visible focus states, and a consistent reading order. Do not expose confidential screenshots or data.

## Acceptance criteria

- The flagship project name and approved description are exact.
- All three supporting projects are shown with approved one-line descriptors.
- Every visual is labeled NDA-safe or placeholder as appropriate.
- The flagship has a route to Case Study.
- No metrics, outcomes, client details, or links are invented.

## Unresolved details

- Project dates, roles, contributions, outcomes, and approved links.
- Supplied visual assets and exact NDA-safe labels.
- Whether supporting cards need destinations.
- Responsive and mobile layout are not approved.

## Implementation status

Specification approved; implementation not started.
